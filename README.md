# Customer_Behavior
# 🛒 Customer Shopping Behavior Analysis

### End-to-End Data Analytics Project | Python • SQL • PostgreSQL

An end-to-end data analytics project that explores customer shopping behavior to identify purchasing patterns, customer segments, product preferences, discount usage, and revenue trends.

The project uses Python for data preparation and feature engineering, PostgreSQL for business analysis, and SQL queries to generate meaningful business insights.

---

## 📌 Project Overview

The objective of this project is to analyze customer shopping data and understand how customers interact with products, discounts, subscriptions, and different purchasing methods.

By analyzing customer transaction data, this project aims to help businesses make better decisions regarding marketing strategies, customer retention, product performance, and sales improvement.

## 🎯 Project Objectives

- Analyze customer purchasing patterns.
- Compare revenue generated by different customer groups.
- Identify popular products and product ratings.
- Understand the impact of discounts on purchases.
- Analyze subscription and customer loyalty behavior.
- Explore revenue contribution across different age groups.

## 📊 Dataset Information

The dataset contains **3,900 customer records and 18 original features**.

Important attributes include:

- Customer ID
- Age and Gender
- Item Purchased
- Product Category
- Purchase Amount
- Location
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Previous Purchases
- Payment Method
- Frequency of Purchases

## 💡 Business Questions Answered

The project addresses 10 important business questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent more than the average purchase amount?
3. What are the top 5 products with the highest average review ratings?
4. How does average purchase amount compare between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which 5 products have the highest percentage of purchases with discounts?
7. How many customers belong to New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

## 📈 Key Analysis Areas

- **Revenue Analysis:** Comparison of revenue across customer groups.
- **Product Analysis:** Product popularity and customer ratings.
- **Discount Analysis:** Understanding discount usage and purchasing behavior.
- **Customer Segmentation:** New, Returning, and Loyal customer classification.
- **Subscription Analysis:** Comparing subscribers and non-subscribers.
- **Age Group Analysis:** Understanding revenue distribution across age groups.

## 🚀 How to Run the Project

### Prerequisites

Install the following:

- Python
- Jupyter Notebook
- PostgreSQL
- pgAdmin (optional)

### Step 1: Clone the Repository

```bash
git clone https://github.com/codebydhirajpatil/Customer_Behavior.git
```

```bash
cd Customer_Behavior
```

### Step 2: Install Dependencies

```bash
pip install pandas sqlalchemy psycopg2-binary jupyter
```

### Step 3: Prepare the Dataset

Make sure the CSV filename matches the path used in the notebook:

```python
df = pd.read_csv('customer_shopping_behavior.csv')
```

### Step 4: Run the Python Notebook

Open Jupyter Notebook:

```bash
jupyter notebook
```

Open `customer_Shopping_Behavior_Analysis.ipynb` and execute the cells.

### Step 5: Configure PostgreSQL

1. Open PostgreSQL or pgAdmin.
2. Create a database named `customer_behavior`.
3. Configure your database connection using your own credentials.
4. Run the notebook's database integration section.

**Security:** Store database credentials in environment variables rather than hardcoding them in the notebook.

### Step 6: Execute SQL Queries

Open `coustomer query.sql` in pgAdmin or another PostgreSQL SQL editor.

Run the queries to explore the business questions and generate insights.
